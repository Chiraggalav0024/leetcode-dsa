RULE FOR SOLVING
================

For EVERY problem:

1. Understand the problem.
2. Write examples manually.
3. Think of brute force first.
4. Determine brute-force time complexity.
5. Identify the bottleneck.
6. Look for a DSA pattern.
7. Try to derive the optimized solution yourself.
8. Write the code without looking at the solution.
9. Test edge cases.
10. Analyze time complexity.
11. Analyze space complexity.
12. Understand WHY the algorithm works.
13. Reimplement the solution from memory.
14. Solve 1–3 similar problems afterward.
